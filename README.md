# ECHO: ONE OF ONE

Qollab × IonQ Hackathon 2026, theme **Quantum Unlocked**. A playable third-person cyberpunk game that teaches no-cloning, entanglement/no-signalling and quantum teleportation through real Qiskit circuits.

- **The Qollab project is [`echo/`](echo/)**: upload that folder as-is. Its README is the project page.
- Vision and plan: [ECHO_MASTER_VISION.md](ECHO_MASTER_VISION.md), [ROADMAP_48_HOURS.md](ROADMAP_48_HOURS.md), [QOLLAB_DEPLOYMENT.md](QOLLAB_DEPLOYMENT.md), [CLAUDE_CODE_PROMPTS.md](CLAUDE_CODE_PROMPTS.md).
- Everything outside `echo/` (vault, scripts, `.claude/`) is the agent organisation that builds it.

This effort is supported by Qollab & IonQ. [MIT](LICENSE).
