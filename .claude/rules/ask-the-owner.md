# Ask the owner; never assume

Owner ruling, 2026-10-09, verbatim: "ask me if you have any questions going forward. do not assume anything. if you need anything, or if you're not sure of something, ask me".

- A choice the vision docs (`ECHO_MASTER_VISION.md`, `ROADMAP_48_HOURS.md`, `QOLLAB_DEPLOYMENT.md`, `CLAUDE.md`) do not settle is a question, not a default. Workers put it in their report under `## Questions for the owner`; supervisors raise it with `=== ASK_OWNER ===`.
- Keep building what IS settled while a question waits; never stall a lane on one open point.
- The vision docs are owner-only. A worker or supervisor that thinks one is wrong proposes the change in its report; it never edits the doc.
