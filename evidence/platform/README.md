# evidence/platform: platform lane captures

One subfolder per gate. `g0-input-diagnostic/` holds the 10c input diagnostic and auto-send runs. `g0/` holds the G0 platform smoke on the local runner, produced by `tools/qollab-runner/check.cjs` (default output `evidence/platform/g0`) and `tools/qollab-runner/sabotage.sh`. Each subfolder has its own README listing the commands and exit codes.
