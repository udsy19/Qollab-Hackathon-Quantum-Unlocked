# Submission checklist

Deadline: **Sun Oct 11, 19:00 ET.** Up to five projects; each is judged on its own.

## Eligibility (all required)
- [ ] Qiskit project that runs on Qollab's free simulators, including IonQ's simulator (`python main.py --backend ionq`)
- [ ] Published and runnable on Qollab under the MIT license, before the deadline
- [ ] Qollab project page explaining what it does and how to run it (adapt README.md)
- [ ] Built during the window; any pre-existing code disclosed in README → Disclosures
- [ ] 2–3 minute demo video at a public link, no sign-in; link in README

## Judging rubric (local and global use the same four)
- [ ] **Novelty & creativity**: a fresh angle on the topic, not a rehash of a textbook figure
- [ ] **Technical execution**: circuits are correct and actually run on the IonQ simulator
- [ ] **Impact potential**: who learns from this, and how it could keep being used after the hackathon
- [ ] **Documentation quality**: README/project page lets a stranger run it and follow it

## Quantum Unlocked theme bar
Pick a hard, timely topic (error correction, fault tolerance, quantum networking, algorithms) and teach it through an interactive demo, animation, visualisation or GUI that makes it intuitive.
